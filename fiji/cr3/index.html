Canon CR3 Sensor Importer for Fiji

Open a supported Canon CR3 file as a 16-bit grayscale image with one pixel per Bayer sensor site. The importer preserves the camera's recorded values and sensor margins. You can inspect the Bayer pattern and available capture metadata under Image → Show Info….

Install with the Fiji updater

  1. In Fiji with Java 21 or newer, choose Help → Update… → Manage update sites → Add Unlisted Site.
  2. Enter Canon CR3 Sensor Importer as the name and use this URL:
    https://carstenartur.github.io/Photographer/fiji/cr3/
  3. Enable the site, close the site manager, choose Apply changes and restart Fiji.
  4. Choose File → Import → CR3 Sensor Data… and select a CR3 file.
