Canon CR3 Sensor Importer for Fiji

Import the original Bayer samples from supported Canon RAW and C-RAW files. Fiji displays the 16-bit sensor plane in grayscale, with one camera value per Bayer site. The importer preserves the recorded values and sensor margins. You can inspect the Bayer pattern and available capture metadata under Image → Show Info….

The shared Java reader also supports the camera's embedded color JPEG and experimental RGB development of supported RAW and C-RAW files. The CR3 Sensor Data… menu command opens the Bayer samples for measurement.

Install with the Fiji updater

  1. In Fiji with Java 21 or newer, choose Help → Update… → Manage update sites → Add Unlisted Site.
  2. Enter Canon CR3 Sensor Importer as the name and use this URL:
    https://carstenartur.github.io/Photographer/fiji/cr3/
  3. Enable the site, close the site manager, choose Apply changes and restart Fiji.
  4. Choose File → Import → CR3 Sensor Data… and select a CR3 file.

Open a color image

After installing the update site, open the example in Fiji’s Script Editor and run it. Choose a CR3 file. Clear Develop RAW to RGB to open the camera’s color JPEG. Select it to demosaic a supported RAW or C-RAW stream into sRGB.
