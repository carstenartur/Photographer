# Photographer 0.1.7

This release improves CR3 and DNG data correctness, documents the decoder's implementation contracts, and adds reliable paired mock-camera capture for Fresnel. The standalone CR3 libraries and Fiji importer require Java 21 or newer; the application requires Java 25.

## CR3 and DNG corrections

- Unsigned TIFF rational values retain their full 32-bit range. Big-endian inline byte metadata, including the GPS altitude reference, is read correctly.
- Native Bayer reads reject destinations that cannot preserve unsigned 16-bit samples. DNG region reads respect subsampling, destination offsets and selected bands without overwriting surrounding pixels.
- Preview selection uses an independent options snapshot and restores the caller's configuration when disabled.
- CR3 readers support a nonzero stream origin, validate container offsets and preserve stream state while probing. Metadata schemas, reader lifecycle checks and DNG layout detection follow the ImageIO contracts.

The default ImageIO read continues to develop an 8-bit RGB photograph from the full RAW image. Explicit `rawSensor()` reads return native sensor codes in unsigned-short storage. The stable public API remains as described in the [API boundaries](../cr3-api-boundaries.md). [CR3 QA changes](https://github.com/carstenartur/Photographer/pull/416) · [ImageIO guide](../cr3/imageio.md)

## Capture and web interface

- CCAPI operations are selected by their complete advertised operation, with native transport preflight checks. [PR #411](https://github.com/carstenartur/Photographer/pull/411)
- Fresnel can pair with Photographer and request a durable external still capture from a mock camera, with status and recovery documented in the [capture guide](../fresnel-capture.md). Physical-camera integration remains follow-up work. [PR #412](https://github.com/carstenartur/Photographer/pull/412)
- Interactive observer cards have a keyboard-accessible button and visible focus. Compatible frontend dependency updates remove additional audit findings; the remaining development-tool Picomatch advisory is tracked in [TODO.md](../../TODO.md). [PR #415](https://github.com/carstenartur/Photographer/pull/415)

## Documentation and validation

The [CR3 manual](../cr3/index.md) now explains container offsets, stream ownership, borrowed row buffers, worker and memory behavior, lossless predictor state, C-RAW wavelet reconstruction, and ImageIO destination rules. A [minimal Maven example](../cr3/imageio.md#run-the-minimal-example) demonstrates full-color and native Bayer reads. The [clean-room reviewer guide](../cleanroom/reviewer-guide.md) links the implementation to its evidence.

The product changes passed [main CI](https://github.com/carstenartur/Photographer/actions/runs/44246508577), including Maven unit/integration checks, frontend tests/lint/build and the packaged Docker/Chromium smoke test. The [Java 21 packaged consumer](https://github.com/carstenartur/Photographer/actions/runs/44246508547) and [full JMH, allocation and focus-stack benchmarks](https://github.com/carstenartur/Photographer/actions/runs/44246508697) also passed. The QA changes include targeted Java 21/25 regression checks and reference-evidence replay; this release does not extend the documented physical-camera support matrix.

## Distribution

Use the [GitHub release](https://github.com/carstenartur/Photographer/releases/tag/v0.1.7) for the executable application and Fiji ZIPs. The six standalone CR3 artifacts use version `0.1.7` under `io.github.carstenartur`; `cr3-imageio` brings in the other five libraries. The release workflow verifies and publishes these artifacts through the existing [Maven release process](../cr3-maven-central.md) and updates the [Fiji update site](../cr3/fiji-update-site.md).
