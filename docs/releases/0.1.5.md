## CR3 and Fiji

- The Java 21 libraries extract the camera JPEG, read native Bayer values and develop RGB for the measured 14-bit V1 lossless and three-level C-RAW layouts. [Decoder and supported profiles](../cr3/decoder.md)
- ImageIO writes lossless CR3 for four measured camera profiles and reads and writes uncompressed Bayer DNG. Runnable examples cover both formats. [ImageIO guide](../cr3/imageio.md)
- Fiji's **CR3 Sensor Data…** command shows the sensor values in a single unsigned 16-bit image. The downloadable Groovy example opens the camera's color JPEG or develops the RAW data to RGB. Both modes were run under Java 21 using the released Fiji JARs. [Fiji guide](../cr3/fiji-update-site.md) · [Hosted site and script](https://carstenartur.github.io/Photographer/fiji/cr3/)
- The CR3 reader and writer provenance connects their source inputs, comparison records and contributor statements to the released code. [Clean-room reviewer guide](../cleanroom/reviewer-guide.md)
