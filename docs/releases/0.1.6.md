# Photographer 0.1.6

The GitHub release contains the executable application and the Fiji distribution. The six standalone CR3 libraries are available from Maven Central for Java 21 and newer. [GitHub release and downloads](https://github.com/carstenartur/Photographer/releases/tag/v0.1.6) · [Maven release build](https://github.com/carstenartur/Photographer/actions/runs/44048572553/job/133921749672) · [Maven Central publication](https://github.com/carstenartur/Photographer/actions/runs/44054960109) · [Fiji publication](https://github.com/carstenartur/Photographer/actions/runs/44057351922) · [Tagged source](https://github.com/carstenartur/Photographer/tree/v0.1.6)

## Java ImageIO changes

`ImageIO.read(file)` now develops the full-resolution photograph from supported RAW and C-RAW files. It uses recorded white balance when the capture contains supported CTMD ColorData. In 0.1.5 the default read returned the camera's embedded JPEG. Set `setPreviewOnly(true)` to select that JPEG explicitly. [ImageIO guide](../cr3/imageio.md)

## Maven coordinates

For standard Java ImageIO, add `io.github.carstenartur:cr3-imageio:0.1.6` to your application. It brings in `cr3-core`, `cr3-processing`, `cr3-codec`, `cr3-metadata` and `cr3-container` at the same version. In the guides bundled inside the 0.1.6 JARs, use `0.1.6` wherever an example shows `REPLACE_WITH_CR3_VERSION`. [Maven Central artifact](https://central.sonatype.com/artifact/io.github.carstenartur/cr3-imageio/0.1.6) · [Verify the published coordinates](../cr3-maven-central.md#verify-the-published-central-version)
