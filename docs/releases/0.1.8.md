# Photographer 0.1.8

Version 0.1.8 adds full-resolution 16-bit RGB import for supported Canon RAW and C-RAW files in Java and Fiji. Applications can keep the usual 8-bit color read, request three 16-bit color channels, or read the original Bayer measurements. The standalone CR3 libraries and Fiji importer run on Java 21 or newer. Building Photographer and running its application require Java 25.

## CR3 and ImageIO

- `ImageIO.read(file)` continues to return developed 8-bit sRGB. Select `rawProcessed().bitDepth(Cr3DecodeOptions.BitDepth.SIXTEEN)` to retain fractional values through color processing and quantize once into three unsigned 16-bit bands. The default RGB16 encoding is sRGB. Set `applySrgbConversion(false)` for linear RGB16. RAW color rendering remains experimental. [ImageIO read modes](../cr3/imageio.md)
- The active-area crop now includes the final row and column when the camera records inclusive endpoints. A full-sensor `rawSensor()` read retains the margins, sensor coordinates and native codes. [Crop correction](https://github.com/carstenartur/Photographer/pull/424) · [Decoder output modes](../cr3/decoder.md#output-modes)
- ImageIO honors its advertised RGB16 destination types, including linear RGB. For a matching layout and region, it can return the developed image directly and avoid a second full-frame copy. The application's stack preview fallback reads the embedded JPEG when available. [Destination and preview changes](https://github.com/carstenartur/Photographer/pull/422) · [Copy and memory measurements](../cr3/memory-2026-11-19/README.md)

## ImageJ and Fiji

**File › Import › CR3 Color Image...** opens the oriented active area as a composite with red, green and blue 16-bit channels. The normal handoff gives the ImageJ stack ownership of the three decoded channel arrays. Displaying the composite can require additional heap. **CR3 Sensor Data...** opens one unsigned-short plane containing the original Bayer values. Java callers can use `Cr3ColorImporter.open(Path)` or `Cr3SensorImporter.open(Path)` without opening a window. [Plugin and macro examples](../../cr3-imagej/README.md) · [Fiji guide](../cr3/fiji-update-site.md)

## Memory and performance

RAW reads use `AUTO` by default. When the normal-path estimate exceeds the available heap budget, the decoder chooses compact processing and adapts the worker limit for that read. Native sensor output keeps its dense plane and can reduce worker workspace. A complete owned RGB16 image can also reuse Bayer storage and apply orientation in place. `LOW_MEMORY` explicitly selects compact processing. `FAST` keeps the normal path. Each compact read writes one line beginning `CR3 low-memory:` to stderr with the selected worker limit. The estimate is advisory, and the final image still needs to fit. [Heap policy and options](../cr3/import.md#limited-heap)

On four measured RAW and C-RAW files, Java 21 complete RGB16 reads took **5.31% to 13.66% less time** than the preceding development implementation on four CPUs. For the EOS R RAW file the median went from 630.60 to 589.76 ms. Each observation opened and decoded the file afresh. The timer ended when ImageIO returned the image, before any Fiji window or display rendering. Full numeric fingerprints, dimensions, channel counts and sample depths matched the reference in all 65 successful reads in the final correctness matrix. [Measurements and reproducible evidence](../cr3/optimization-2026-11-19/README.md)

On Java 25, `--add-modules=jdk.incubator.vector` enables an optional accelerator for the packed RGB8 color matrix on supported hardware. Both Fiji menu commands use other paths and need no vector flag. [Optional SIMD requirements](../cr3/imageio.md#optional-simd-color-matrix-on-jdk-25)

## Distribution

Use the [0.1.8 GitHub release](https://github.com/carstenartur/Photographer/releases/tag/v0.1.8) for the application and Fiji ZIP archives. Java applications can depend on `io.github.carstenartur:cr3-imageio:0.1.8` for the six standalone CR3 libraries. [Maven setup and verification](../cr3-maven-central.md#verify-the-published-central-version)

For a source build, use the [local Maven instructions](../cr3/imageio.md#use-a-local-build) or [build the Fiji installation and update-site archives](../cr3/fiji-update-site.md#build-both-archives).
