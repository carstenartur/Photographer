# Photographer 0.1.9

For supported Canon RAW and C-RAW files, `ImageIO.read(file)` now returns a developed sRGB image with three unsigned 16-bit channels. Applications that depend on packed 8-bit pixels can select `Cr3DecodeOptions.BitDepth.EIGHT` explicitly. Use `image.getRaster().getSample(x, y, band)` to access a channel at full precision. The Fiji **CR3 Color Image...** command already supports 16-bit color in 0.1.8. [ImageIO guide](../cr3/imageio.md)

The clean-room decoder's reference panels now cover 61 recordings from 23 camera models. Coverage is documented per recording mode. The release also improves CR3 import performance and adds optional Java 25 vector acceleration for eligible C-RAW files. The standalone reader continues to support Java 21. [Camera coverage](../cr3/camera-coverage.md) · [Performance measurements](../cr3/wavelet-simd-performance.md)

The Wildlife Observer can now use local bird detection to trigger camera capture. Camera profile actions and preview requests are serialized to prevent conflicting operations.
