# RG1 — LibRaw-guided first-reference divergence

## Question

Can the existing manifest-bound LibRaw RAW-linear mosaics locate the earliest point at which the unchanged research CRX decoder contradicts the correct sensor values, and does neutralizing the known first-sample DC/pedestal mismatch expose a longer correct prefix?

## Clean-room inputs

- eleven lossless CR3 fixtures from the fixed G5 X Mark II and EOS R panel;
- 88 lossless single-subband tile/plane streams;
- hash-bound `RAW_LINEAR` TIFF references generated by rawpy 0.27.0 / LibRaw 0.22.1 as a black box;
- the unchanged `CrxNormativeLosslessCandidate` HYBRID baseline and its existing symbol trace.

No LibRaw, dcraw or other third-party decoder source was consulted. Production decoder code was not changed.

## One diagnostic variable

Every stream was run in two explicitly separated modes:

1. `CONFIGURED_BASELINE` — retain the historical first-pixel seed `0`;
2. `REFERENCE_FIRST_SAMPLE_ORACLE` — change only the first-pixel seed to the correct first reference sample for that stream.

The oracle mode is an isolation experiment. It deliberately uses expected output to remove the already-known DC/pedestal discrepancy and is not a proposed decoder algorithm.

## Results

### Configured baseline

All 88 streams diverged at symbol `0`.

At that point the decoder used predictor `0`, decoded unsigned symbol `0`, reconstructed value `0`, and contradicted reference first samples in the range `1984..2149`. This confirms the already-known first-sample DC/pedestal mismatch but does not localize later entropy behavior.

### Reference-first-sample oracle

Setting only the first-pixel seed to the corresponding reference value removed the symbol-0 mismatch in all streams. It did not produce a substantial correct prefix.

| Matched reference samples before first divergence | Streams |
|---:|---:|
| 1 | 71 |
| 2 | 9 |
| 3 | 4 |
| 4 | 2 |
| 6 | 2 |

- median matched prefix: `1` sample;
- mean matched prefix: `1.375` samples;
- maximum matched prefix: `6` samples;
- all 24 EOS R streams diverged at symbol `1`;
- the 64 G5 X Mark II streams had prefix lengths from `1` to `6`.

At the first divergence in every one of the 88 oracle-seeded streams:

- classification was `SYMBOL_OR_RESIDUAL_INTERPRETATION`;
- predictor context still agreed with the reference-derived predictor;
- `K before = 0` and `K after = 0`;
- quotient and remainder were both `0`;
- decoded unsigned symbol and signed residual were both `0`;
- the reference required a non-zero signed residual;
- expected residuals ranged from `-131` to `+119`;
- 45 expected residuals were positive and 43 were negative.

The first disagreement therefore occurred exactly when the reference stream first left the constant value established by the oracle seed. The current candidate continued to consume a zero bit as another zero residual.

## Decision

Final verdict:

```text
COMPLETE: PEDESTAL_ONLY_INSUFFICIENT_AND_EARLIEST_NONZERO_SYMBOL_UNEXPLAINED
```

The reference-first-sample seed proves that a missing constant DC/pedestal is not the sole cause of the current reconstruction failure. After initialization is neutralized, the candidate still fails before it successfully decodes a non-zero reference residual.

This result moves the earliest unresolved boundary ahead of meaningful adaptive-K evaluation for this configuration. It does **not** establish which of the following is responsible:

- additional stream-initialization semantics beyond one scalar seed;
- record framing or bit alignment before entropy symbols;
- an incorrect spatial/plane interpretation;
- an unmodelled sample-domain transform, quantization or scaling;
- a different residual-symbol representation.

The result does not authorize selecting among these possibilities by image-quality fitting or broad parameter search.

## Production decision

No production decoder change.

The deterministic reports are suitable as machine-readable input for a later bounded structural hypothesis or for the controlled closed-loop capture corpus. The next decoder experiment must introduce genuinely new structural evidence rather than another K rule fitted to the current output.
